# Validation records

- [PARITY_RESULT.txt](PARITY_RESULT.txt): saved-data comparisons for version 1.1.0, including ADNI and both NACC cohorts. The record identifies the comparisons actually checked.
- [VALIDATION.json](VALIDATION.json): original package validation metadata.
- [PROVENANCE.json](PROVENANCE.json): original research-file provenance and hashes, relative to the repository root.

These records are preserved from the submission package. The GitHub source layout moves them into this directory; the source library, research scripts, tests, and protocols are unchanged. Repository documentation is maintained separately. The distribution-only manifest checker is omitted because Git tracks repository revisions.
